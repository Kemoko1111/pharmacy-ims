## 2. Communication & working agreement

- **Channel:** WhatsApp group "[GROUP NAME]" for daily coordination; GitHub issues for
  all technical and architectural decisions (brief §2.2 rule 2).
- **Standup:** every [DAY] at [TIME], 15 minutes, [LOCATION / online]. PM records
  attendance and blockers on the GitHub project board.
- **Working hours:** members respond to team messages within [X] hours between
  [START]–[END]; deep work sessions [DAYS/TIMES].
- **Tooling:** GitHub repository + GitHub Projects board (visible to lecturer). All code
  via pull request with ≥1 peer review; no direct pushes to `main`.

## 3. Decision-making & conflict resolution

1. Attempt consensus within the relevant role pair (e.g., the two engineers for a
   technical call).
2. If unresolved in 24 h, the role owner decides (BA for requirements, UX Lead for
   design, Backend Lead for architecture) and records the decision as an ADR or issue.
3. If the disagreement is cross-cutting or affects the client, the PM calls a vote;
   simple majority; PM breaks ties.
4. Client-facing commitments are made only by the BA or PM, never individually.

## 4. Contribution expectations ("full contribution" per role)

| Role | Full contribution means |
|---|---|
| PM | Board current, weekly standup held, deadlines tracked, blockers escalated ≤24 h |
| BA | Every client interaction documented and signed; requirements doc current |
| UX Lead | Wireframes before build; usability check before every demo; mobile/3G verified |
| Engineers | Assigned issues delivered per sprint; PRs reviewed within 48 h |
| QA/Docs | Test plan executed each sprint; README always reproducible from scratch |

## 5. Consequences for non-fulfilment

1. **First lapse:** raised at standup, noted in minutes, recovery plan agreed.
2. **Second consecutive week:** PM notifies the lecturer in writing (required by brief
   §2.2 rule 5) and the peer-evaluation impact is made explicit to the member.
3. Persistent non-contribution is reflected honestly in the confidential Week 9 peer
   evaluation (30% weight within team marks).
